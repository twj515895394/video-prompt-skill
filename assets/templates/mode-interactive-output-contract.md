# 交互模式输出合同

## 适用条件

只有用户明确表达以下意图时进入交互模式：

- 希望共同讨论或脑暴；
- 希望逐步设计；
- 要求先提问再生成；
- 希望比较多个大方向；
- 明确要求 Grill Me；
- 明确表示暂时不要直接出最终 Prompt。

用户没有明确表达上述意图时，不自动进入交互模式。

## 核心规则

- 每次只问一个最影响结果的问题；
- 每个问题同时给出推荐答案；
- 推荐答案说明必要理由，但不展开无关细节；
- 沿设计依赖顺序推进，先解决上游决策，再进入下游细节；
- 已确认的信息不重复询问；
- 能从请求、上下文和素材推断的内容不追问；
- 只追问会实质改变视频目标、动作、镜头、节拍、连续性或模型能力的变量；
- 用户要求收口，或剩余问题只影响轻微细节时，立即停止提问并完成交付。

## 追问优先级

### 文生视频

```text
核心观看目标
→ 开场画面
→ 主体运动或表演
→ 镜头主任务
→ 节拍与时长
→ 收尾状态
```

### 图生视频

```text
图片职责
→ 必保锚点
→ 从当前状态如何开始运动
→ 镜头如何跟随
→ 最终落点
```

### 多模态参考

```text
每份素材职责
→ 各维度唯一主真源
→ 必须保留与禁止继承
→ 素材之间的兼容性
→ 最终时间轴
```

### 多镜头 / 故事板

```text
全片主线
→ 段落目标
→ 镜间承接
→ 跨镜固定项
→ 每镜动作与镜头
```

### 视频编辑 / 延长

```text
必须保持不变的内容
→ 必须修改或延长方向
→ 允许变化范围
→ 新落点
```

## 单轮问题格式

```text
当前最关键的问题：...

我的推荐：...

原因：...
```

必要时可给 2-3 个方向差异，但必须明确推荐其中一个，不把设计责任全部交还用户。

## 交互阶段允许输出

- 当前唯一问题；
- 推荐答案；
- 与推荐直接相关的方向差异；
- 已确认结论的极简回顾。

不得提前输出：

- 未完成决策的完整 Prompt；
- 同时展开多个问题；
- 大量不影响主方向的细节选项；
- 内部 Reference、目录或加载逻辑。

## 收口条件

满足任一条件即结束追问：

- 用户说“直接出结果”“够了”“按推荐做”；
- 核心观看目标、动作、镜头、节拍和收尾已经可执行；
- 再问只会改变轻微风格或装饰细节；
- 用户明确不希望继续深挖。

## 最终交付

收口后读取当前任务模板，并按需要输出：

- 一份最终可复制 Prompt；
- 多镜头 Prompt Pack；
- 必要的素材职责和固定项；
- 简短方向决策摘要；
- 只有确有价值时才提供备选版本。

交互模式最终结果仍必须可直接使用，不能只停留在讨论结论。

## 与快速模式的边界

- 快速模式解决“直接给我可用结果”；
- 交互模式解决“和我一起锁定重大方向”；
- 两种模式共用相同输入、任务、控制、资料和模型适配；
- 差异只在是否需要用户参与重大决策，以及最终是否需要附带方向摘要；
- 用户在交互过程中要求直接生成时，立即转入最终交付，不继续追问。
