# Styles Index

风格层负责说明某种视频风格如何通过镜头、表演、光影、材质、节奏和声音被执行，而不是只列风格名称。

每次最多读取一份主 style Reference。题材混合时应确定一个主风格，其他方向只作为轻量修饰。

## cinematic-live-action

适用：电影化写实、剧情短片、情绪片、悬疑、动作和作者化真人影像。

重点：摄影位置、镜头运动、自然表演、光影、色彩、空间和声音共同成立。

## realistic-short-drama

适用：家庭、都市、关系、职场、生活流和竖屏短剧。

重点：可信空间、清晰叙事、克制表演、可读镜头和自然收尾，不把“电影感”当成唯一目标。

## anime-animation

适用：日漫、国漫、动画电影、角色动作和风格化世界。

重点：角色造型锚点、线条和渲染连续性、夸张但可读的动作、发丝与服装动态。

## comic-motion-drama

适用：AI 漫剧、动态漫画、韩漫感、国漫短剧和分镜驱动视频。

重点：角色一致性、画格感、镜头切换、表情表演、动作反馈和有限动画的节奏设计。

## commercial-advertising

适用：产品、品牌、时尚、美妆、食品、汽车和概念广告。

重点：产品外观准确、材质高光、镜头节拍、卖点揭示、品牌落点和音效设计。

## documentary-ugc

适用：纪录片、手机拍摄、Vlog、采访、街头、Bodycam、监控和真实记录感。

重点：设备位置、自然曝光、轻微不完美、真实环境声和不过度设计的镜头。

## experimental-visual

适用：抽象、超现实、梦境、视觉特效、材质变形和概念短片。

重点：先定义视觉变化规则和时序，再定义特效；不能只堆叠形容词。

## 选择规则

- 用户只说“电影感”时，不直接把该词写进最终 Prompt；先拆成可执行变量。
- 设备来源和观看位置属于实现变量，可由 style 引导，但详细术语仍从 controls 或 libraries 获取。
- 题材套路优先从 `libraries/genre-patterns/` 选择，style 负责如何拍出来。
- 模型专属的风格表达方式由 `models/` 最终转换。
