# Combat Fighting Profiles Library

本库只回答“现代格斗有哪些可选动作语言，以及它们通常如何表现”。不决定 Battle Beat、镜头、状态机或输出流程。

选择一个主 Profile，必要时再加一个辅助 Profile。不要在同一 Beat 同时混入多套动作语言。

## Boxing

- 典型距离：拳击中近距离；
- 重心：稳定、脚步持续调整角度；
- 发力：脚—髋—肩链路明显；
- 进攻倾向：刺拳建立距离，直拳 / 摆拳 / 勾拳完成压迫和反击；
- 防守倾向：格挡、偏头、后撤、侧移、抱架；
- 连续性重点：每次出拳后要有回收、防守和脚步调整；
- 镜头重点：肩髋发力、拳路和受击反馈。

## Muay Thai

- 典型距离：踢击距离到肘膝近距离；
- 重心：更适合踢击、膝击和 clinch；
- 发力：髋部旋转、支撑腿和身体整体参与；
- 进攻倾向：低扫、中高踢、膝、肘、直拳组合；
- 防守倾向：提膝 / 抬腿检查、抱架、后仰、clinch 控制；
- 连续性重点：踢击后必须有落脚和重心恢复；
- 镜头重点：髋部旋转、踢击轨迹、肘膝接触和落脚。

## Sanda

- 典型距离：中距离到短暂贴身；
- 重心：兼顾拳腿与快速摔法；
- 发力：步法、踢击和抓摔转换直接；
- 进攻倾向：拳腿组合、接腿、扫摔、快速摔出后脱离；
- 防守倾向：移动、格挡、抓接、反摔；
- 连续性重点：从击打到摔法必须有抓握 / 失衡窗口；
- 镜头重点：换距、抓接时机、摔出方向和落地反馈。

## MMA

- 典型距离：远距打击 → 拳击距离 → clinch → 地面；
- 重心：随阶段明显改变；
- 发力：站立打击与摔跤 / 地面控制连续转换；
- 进攻倾向：打击制造进入、抱摔、压制、地面打击或控制；
- 防守倾向：架手、防摔、贴笼 / 借墙、起身；
- 连续性重点：站立到地面的姿态过渡必须清楚；
- 镜头重点：换层、抓握、身体位置、地面控制关系。

## Wrestling / Grappling

- 典型距离：贴身和地面；
- 重心：低、强调身体接触和支撑点；
- 发力：抱腿、抱腰、转髋、杠杆、压重心；
- 进攻倾向：进入、破坏平衡、摔倒、控制；
- 防守倾向：降重心、防摔、转身、建立支撑、挣脱；
- 连续性重点：抓握位置、身体朝向和支撑点不能跳变；
- 镜头重点：双方身体关系与重心变化，而不是只拍手脚特写。

## Tactical Close Combat

- 典型距离：极近距离；
- 重心：稳定、直接、目标导向；
- 发力：短动作、快速控制、环境借位；
- 进攻倾向：快速打断、控制手臂、推离、压制、脱身；
- 防守倾向：保护头部和中心线、解除抓握、快速重建距离；
- 连续性重点：动作应服务制服 / 脱身 / 保护，不追求表演性长连招；
- 镜头重点：威胁来源、手臂控制、出口和空间关系。

## 混合建议

可用“主 Profile + 辅助 Profile”：

- Boxing + Wrestling；
- Muay Thai + Clinch / Grappling；
- Sanda + Boxing；
- MMA 内部按 Range 自然切换；
- Tactical Close Combat + Wrestling 控制。

辅助语言只在明确的距离变化、抓握成功、失衡或 Turning Event 后进入。

## 使用边界

- Profile 是动作语言，不是必须复刻的真实比赛规则；
- 不凭流派名自动生成一长串招式；
- 用户明确动作设计优先于 Profile 默认倾向；
- 不把体育规则、评分体系和胜负判定写进视频 Prompt，除非用户需要赛事场景。
