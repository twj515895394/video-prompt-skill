# Combat Environment Patterns Library

本库提供“环境怎样参与战斗”的可选模式，不规定 Battle Beat 顺序，也不要求每场战斗都使用环境互动。

核心原则：

> **环境互动必须改变站位、距离、优势、目标关系或镜头接力，而不是纯装饰。**

一个 Beat 原则上只突出一个主要环境交互。

## 狭窄走廊 / Corridor

适合：现代 1v1、1vN、追击与压迫。

可提供：

- 限制横向移动；
- 强化前后距离关系；
- 门框 / 墙面成为短暂阻挡；
- 通过击退、转身、出入口完成 Target Handoff；
- 镜头可以沿走廊轴线跟随，空间更容易保持连续。

风险：人物无原因左右换位、多人同时堵在同一位置、镜头穿墙。

## 墙面 / Doorframe

适合：压制、脱身、换位、短时控制。

可提供：

- 阻止后撤；
- 受击者撞墙形成明显重量反馈；
- 借墙改变身体朝向；
- 门框限制动作幅度并制造单线交战。

风险：人物穿墙、撞击没有反作用、墙面位置跨 Beat 漂移。

## 桌椅 / Furniture

适合：现代动作戏、客栈 / 室内武侠。

可提供：

- 绕行改变攻击角度；
- 撞击导致失衡；
- 跨越 / 推开完成换距；
- 作为短暂遮挡完成镜头或目标接力。

风险：桌椅凭空移动、连续多个 Beat 不断出现新物件、道具破坏只为视觉噪音。

## 柱体 / Pillar

适合：1vN、武侠廊柱空间、现代停车场等。

可提供：

- 切断多人同时接触；
- 绕柱完成 Target Handoff；
- 形成前景遮挡和自然 Cut；
- 改变 Camera Axis 时提供空间重建锚点。

风险：绕柱后人物方向不一致、柱体位置变化。

## 楼梯 / Steps

适合：高低位优势、追逐、多人换位。

可提供：

- 高低位改变攻击角度；
- 上下移动影响重心和速度；
- 跌落 / 后退制造明显 Condition 变化；
- 镜头可以利用层级重建空间。

风险：台阶数量和人物高度关系突然变化、无过渡瞬移到另一层。

## 栏杆 / Rail

适合：限制移动、制造边缘风险、短暂借力。

可提供：

- 阻止继续后撤；
- 借栏杆换位或短距离跃过；
- 形成动作终点和危险边界。

风险：无支撑长时间悬空、栏杆高度和位置不稳定。

## 车辆 / Vehicle

适合：街头动作、停车场、追逐后近身战。

可提供：

- 车身作为空间锚点和遮挡；
- 撞车门 / 引擎盖形成明显受力反馈；
- 绕车完成 Target Handoff；
- 车辆限制移动路线。

风险：车辆尺寸 / 位置漂移、人物穿车体、场景无因果切到车另一侧。

## 竹林 / Trees

适合：电影武侠。

可提供：

- 树干 / 竹子作为绕位锚点；
- 叶片和竹枝反馈动作空气扰动；
- 通过遮挡、绕行和短暂借力完成空间变化；
- 风声和叶片声增强 Audio Choreography。

风险：把竹林变成无物理约束的长期飞行舞台。

## 屋顶 / Roof

适合：电影武侠、高低位追逐与交锋。

可提供：

- 高低落差；
- 屋脊作为移动通道；
- 短距离跃跨改变位置；
- 瓦片、脚步和落地形成声音反馈。

风险：无起跳 / 无落地、屋顶结构不断变化、无支撑远距离飞行。

## 高低差 / Elevated Terrain

适合：现代和武侠通用。

可提供：

- 高位 / 低位攻防差；
- 跳下、跨上、后退跌落形成 Turning Event；
- 镜头通过高度变化自然重建空间。

风险：高度不连续、人物瞬间出现在新层级。

## 使用方法

从当前场景已有物体中选择最自然的一个模式。优先复用用户场景，不为了“丰富动作”强行添加新环境道具。

环境互动的结束结果至少要改变以下一项：

- Position；
- Range；
- Advantage；
- Condition；
- Target；
- Camera / Visual Handoff。
