# Combat Weapon Profiles Library

本库提供刀、剑、枪、棍的武侠动作语言选项。它不负责 Combat 状态机，也不提供固定招式套路。

所有兵器 Profile 都必须服从：持握连续、距离连续、轨迹可读、接触有反馈、Beat 结束位置可继承。

## 刀 / Saber

- 典型距离：中距离到近距离；
- 动作倾向：劈、斩、扫、压、格挡，轨迹更直接有重量；
- 发力：肩背、腰胯和步法共同参与；
- 防守：以格挡、压制、偏开对方兵器为主；
- 节奏：更强冲击、更明显攻守方向；
- 镜头重点：刀路弧线、重心、接触点、受力后的刀身和手臂落位。

## 剑 / Jian

- 典型距离：中距离；
- 动作倾向：刺、点、挑、削、格、引、偏转；
- 发力：更强调腕、臂、身法与精确轨迹协同；
- 防守：偏转、引开、借角度化解；
- 节奏：更轻快、精确、富有拆招关系；
- 镜头重点：剑尖方向、交锋角度、短暂反击窗口和身法换位。

## 枪 / Spear

- 典型距离：长兵器距离；
- 优势：长度、直线压迫、区域控制；
- 动作倾向：刺、拦、拿、扫、挑、回枪；
- 发力：双手、腰胯、步法和枪身整体协同；
- 防守：枪杆可以格、压、拨、封线；
- 节奏：通过距离控制迫使对方绕行、偏转或冒险贴身；
- 镜头重点：枪尖路径、枪杆方向、双方距离和贴身换距的 Turning Event。

## 棍 / Staff

- 典型距离：中长距离；
- 动作倾向：扫、劈、点、拨、架、撑；
- 发力：双手杠杆、腰胯旋转、步法配合；
- 防守：大范围格挡和空间封锁；
- 节奏：适合连续变向和环境空间互动；
- 镜头重点：棍身整体轨迹、双手位置和扫击影响范围。

## 不同兵器对抗

不同兵器的重点不是“谁数值更高”，而是距离与动作窗口：

- 长兵器通常先拥有距离优势；
- 短兵器需要通过偏转、绕位、环境遮挡或身法贴身缩短距离；
- 一旦进入近距离，长兵器可能需要回收、横架、转杆或重新拉开；
- 缴械 / 掉落 / 被夺必须成为明确 Turning Event；
- 兵器改变后，Range 和动作语言必须同步改变。

## Weapon State Continuity

每个关键 Beat 内部至少跟踪：

- 谁持有兵器；
- 左 / 右 / 双手持握；
- 兵器大致朝向；
- 是否正在接触、格挡或被压制；
- 是否发生换手、脱手、掉落、拾取；
- 结束时兵器落位。

只有发生明确动作时才能改变这些状态。

## 使用边界

- 不列固定套路和招式百科；
- 不把兵器名当作风格标签；
- 不默认加入火花、能量、剑气等视觉特效；
- 用户已有明确兵器动作时优先保留，只补距离、轨迹、反馈和连续性；
- 兵器与空手切换时必须有明确过渡动作。
