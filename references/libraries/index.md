# Libraries Index

资料库负责提供“有哪些具体选项、术语、结构和详细资料”，不决定任务流程，也不代替控制规则。

每次按当前任务需要读取 `0-2` 份资料库叶子文件。

## camera-shot

包含：

- 景别；
- 视角与机位；
- 焦段、景深和镜头类型；
- 推、拉、摇、移、跟、环绕、升降、穿越等运镜；
- 情绪镜头、动作镜头和空间镜头术语。

## action-motion

包含：

- 蓄力、接触、反馈、恢复；
- 打击帧；
- 奔跑、追逐、舞蹈、体育运动；
- 物体运动和环境反馈；
- 动作拆解示例结构。

## performance-expression

包含：

- 表情和微表情；
- 眼神落点；
- 嘴角、眉眼、呼吸、停顿和小动作；
- 对白表演；
- 不同关系和情境下的表演选项。

## transition-effects

包含：

- 匹配剪辑；
- 遮挡转场；
- 甩镜、穿越、变形、溶解；
- 时间、空间和材质变化特效；
- 特效使用边界。

## lighting-color

包含：

- 光源方向和光影类型；
- 阴影色、高光色和主体分离；
- 电影级色调；
- 时间、天气和环境光变化；
- 光影连续性选项。

## audio-sound

包含：

- 对白、旁白和耳语；
- 环境音、拟音和动作音效；
- BGM 结构；
- 节拍和声音层次；
- 声音空间与远近关系。

## genre-patterns

包含：

- 写实短剧；
- AI 漫剧；
- 动作、悬疑、情绪、广告、纪录和 UGC；
- 题材级镜头组合；
- 常用叙事节拍与风格搭配。

## 使用边界

- 资料库回答“可以选什么”，控制层回答“为什么选、如何协调”。
- 资料库内容可以被多个任务引用，但物理正文只保留一份。
- 不把社区长 Prompt 直接作为资料库正文；只保留抽象后的结构、变量、适用条件和失败边界。
- 风格的完整实现方法进入 `styles/`，模型专属语法进入 `models/`。
