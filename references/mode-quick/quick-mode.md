# Quick Mode

## 目标

在用户直接要结果时，快速给出能落地的视频 Prompt 和时间轴。

## 适用信号

- 用户要结果，不要讨论过程
- 当前核心不确定项主要是镜头、节拍、光影
- 已经能判断主体、场景和任务类型

## 默认动作

1. 先锁主体运动
2. 再锁镜头主任务
3. 再补光影、色调、节拍和限制项
4. 默认给 `1` 个主方案；确实有价值时再给备选

## 允许主动补全

- 单片段默认时长
- 镜头切分密度
- 光影和色调支撑
- 连续性限制
- 常规收尾方式

## 不允许主动补全

- 新剧情线
- 新人物
- 大世界观设定
- 与已有参考图冲突的强动作
- 用户没提过的复杂蒙太奇结构

## 即使在快速模式也要追问

- 图像类型判不出来
- 多张参考图冲突
- 主体运动和镜头运动要求互相打架
- 多片段任务没有核心节拍，无法切时间轴

## 输出骨架

```text
视频概述：
主要约束：
镜头级时间轴：
镜头 Prompt：
备选 Prompt：
已自动补全项：
```

## 自查清单

- 是否先写时间顺序，再写风格
- 是否区分主体运动和镜头运动
- 是否写了自然收尾
- 是否补了真正相关的一致性限制
