# Modern Combat Playbook

## 1. 适用范围

用于现代写实 / 电影化近身格斗，包括拳击、泰拳、散打、MMA、摔跤 / 缠斗、战术近身动作语言及其合理混合。

本页只定义现代格斗的专项执行差异，通用状态机、镜头连续性、声音和输出规则读取 `core-playbook.md`。

## 2. 默认强度

- Level 1｜写实近身格斗：动作短、重心真实、防守和恢复明确；
- Level 2｜电影化现代动作（默认）：保留真实物理，同时增强节奏、连续性和镜头可读性；
- Level 3｜强化动作片：更密集、更强环境利用和爆点，但禁止超级英雄式无重量感。

用户已有明确动作风格时优先服从用户，不机械套等级。

## 3. 默认节奏倾向

可参考：

> **快速观察 → 首次接触 → 连续压迫 → 攻守反转 → 近身缠斗 / 控制 → 终结**

这只是常见倾向。短视频可以只保留其中 2–4 个有效阶段，长镜头也可以围绕单一压迫关系持续发展。

## 4. 现代格斗的动作逻辑

重点维护：

- 明确发力来源和重心变化；
- 每次逼近 / 后撤 / 侧移都改变距离和角度；
- 防守动作必须影响下一动作窗口；
- 命中后需要失衡、疼痛、阻滞、撞击或短暂恢复；
- 连招不是连续命中清单，而是攻防交互；
- 从站立打击进入 clinch / wrestling / ground control 必须有距离和姿态过渡；
- 离开缠斗也需要推开、转身、挣脱、借墙或其他合理动作。

## 5. 现代 Range 映射

按需要可更具体地理解为：

- 远距离 / 踢击距离；
- 拳击距离；
- 肘膝近距离；
- clinch；
- grappling / ground control；
- disengage / reset。

最终 Prompt 不需要写这些标签，只描述动作如何进入或离开该距离。

## 6. 主流派 + 辅助流派

允许混合，但一个 Beat 只保留一个主动作语言。

例如：

- Boxing 主导，失衡后切 Wrestling；
- Muay Thai 主导，贴身后进入 clinch；
- Sanda 主导，抓到时机后完成摔法；
- Tactical Close Combat 主导，必要时短暂使用关节控制。

辅助流派只能在明确转换节点出现，避免每个动作都换一套体系。

## 7. 1vN

现代多人战强调：

- 主角主动移动，避免长时间站在包围中心；
- 环境和身体位置用于制造单线接触；
- 当前主目标清楚，其他对手状态明确；
- Target Handoff 通常由击退、转身、新威胁入画或空间换位触发；
- 镜头优先保持主目标和下一个威胁可读。

禁止多人同时围绕主角无序出拳。

## 8. 环境互动

优先使用真实可解释的环境：墙、门框、桌椅、柱体、楼梯、栏杆、走廊、车辆、狭窄出入口。

环境互动必须改变战斗状态，例如：

- 借墙阻止后撤；
- 绕柱切断多人同时进攻；
- 撞桌导致失衡；
- 楼梯改变高低位优势；
- 门框限制横向移动。

不要把环境互动写成纯装饰破坏效果。

## 9. Camera 重点

现代格斗优先保证：

- 重心和接触点可见；
- 攻防双方同时在可读范围；
- 重击可以短暂更近，但不要长期只拍碎片特写；
- 长镜头时镜头速度不超过演员动作可读性；
- 快切时每次 Cut 必须继承攻击方向、受击方向或空间锚点。

## 10. Audio 重点

根据场景选择：鞋底摩擦、呼吸、拳脚破风、身体接触、墙面 / 地面撞击、衣料拉扯、环境回声。

BGM 可以强化节奏，但关键命中处可短暂让位给真实接触声。

## 11. 常见高风险项

- 无准备的连续大招；
- 每拳都完整命中；
- 受击者没有失衡或恢复；
- 从远距直接瞬间进入抱摔；
- 站立 / 地面状态无过渡切换；
- 1vN 中所有对手同时成为主目标；
- 镜头晃动强到看不清动作；
- Level 3 变成超人式飞打和无重量落地。
