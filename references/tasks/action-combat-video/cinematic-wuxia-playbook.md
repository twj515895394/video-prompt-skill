# Cinematic Wuxia Playbook

## 1. 适用范围

用于电影武侠 / 武术动作，包括空手武术与刀、剑、枪、棍交锋。

默认是**电影武侠，不是仙侠**。通用状态机、镜头连续性、声音和输出规则读取 `core-playbook.md`。

## 2. 默认强度

- Level 1｜写实武术：基本不超出现实人体合理范围；
- Level 2｜电影武侠（默认）：允许短距离腾跃、踏墙、滑步、借力飞身、轻微滞空，但必须有起跳、路径和落地；
- Level 3｜高武武侠：允许更长飞跃和更强滞空，但仍不进入剑气、能量波、御剑、法器和长距离无支撑飞行。

用户明确要求更写实或更高武时按用户意图调整。

## 3. 默认节奏倾向

可参考：

> **对峙 / 留白 → 试招 → 拆招往复 → 身法 / 兵器转折 → 高潮交换 → 收势**

武侠允许在爆发前后保留呼吸和留白，但短视频不必机械包含全部阶段。

## 4. 武侠动作逻辑

重点维护：

- 读招、接招、化解、借力和反击之间的因果；
- 身法必须改变位置、角度或距离，而不是纯漂浮；
- 腾跃必须有起跳点、空中路径、目标和落地状态；
- 衣袂、发丝、尘土和兵器轨迹可以辅助表达动势，但不能代替主体动作；
- 收势有表达价值，结束姿态应继承前一动作 momentum。

## 5. 兵器连续性

兵器场景必须持续维护：

- 当前持握手；
- 握持方式是否变化；
- 兵器方向和大致轨迹；
- 攻防距离；
- 格挡 / 招架 / 偏转后的落位；
- 是否脱手、掉落、被夺或重新拾取；
- Beat 结束时兵器位置。

禁止兵器无原因变形、长度变化、消失、凭空换手或从错误方向重新出现。

## 6. 武侠 Range

长兵器与短兵器的距离优势必须能在动作中看出来。

例如：

- 长枪通过距离保持压制；
- 剑手通过偏转枪头或贴身换距消除长度优势；
- 刀剑近距离交换与长兵器中远距离控制采用不同节奏；
- 缴械后重新进入空手近距关系。

最终 Prompt 写动作因果，不写抽象 RPG 属性。

## 7. 主流派 + 辅助流派

支持主流派 + 辅助流派，但一个 Beat 只保留一个主动作语言。

例如：

- 咏春近距主导，借推离进入更长距离；
- 八极爆发主导，转折后切短暂擒拿；
- 太极式借力作为反转节点；
- 剑法主导，失去兵器后进入空手武术。

流派用于决定距离、重心、发力、攻防节奏和动作倾向，不要求模型复刻具体传统套路。

## 8. 1vN

武侠多人战允许更强身法与空间流动，但仍需保持主目标机制。

Target Handoff 可以由：

- 兵器轨迹带向下一目标；
- 腾跃落位后自然形成新主关系；
- 击退旧目标后顺势面对新威胁；
- 柱体、门窗、桌案、屋檐等空间遮挡完成切换。

其他对手必须有明确状态，不能全部同时无序进攻。

## 9. 环境互动

常见环境：竹林、石阶、屋顶、廊柱、桌案、门窗、栏杆、树干、高低地形。

环境互动应改变：

- 站位；
- 距离；
- 高低位；
- 兵器轨迹；
- 镜头接力；
- Target Handoff。

Level 2 下可以借力踏墙、越桌、短距离跃上高处，但必须保留物理起点和落点。

## 10. Camera 重点

武侠镜头优先展示：

- 双方招式关系和兵器轨迹；
- 身法的空间路径；
- 高低位变化；
- 关键拆招或借力节点；
- 高潮后明确收势。

不要因为追求华丽而让镜头与人物同时高速旋转导致动作不可读。

## 11. Audio 重点

按场景需要选择：脚步落点、衣袂破风、兵器挥动、刀剑碰撞、枪棍撞击、木板 / 瓦片 / 石阶反馈、呼吸、环境风声、竹叶或空间回声。

音乐可以更具东方电影感，但不必持续满铺；关键兵器接触和落地可以让音乐短暂让位。

## 12. 高风险项

- Level 2 无原因变成长距离飞行；
- 无起跳直接悬空；
- 腾跃没有落地；
- 兵器轨迹、持握和长度不连续；
- 只写“剑法凌厉 / 身法飘逸”而无具体动作；
- 每次格挡后双方位置重置；
- 频繁跨轴导致攻防方向翻转；
- 非高武场景出现仙侠能量效果。
