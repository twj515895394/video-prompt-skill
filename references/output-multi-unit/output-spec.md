# Multi Unit Output Spec

## 目标

规范多片段视频的对外输出，让段落清楚、承接明确。

## 适用场景

- 有起承转合
- 有多个动作节点
- 有明显情绪节拍变化

## 输出骨架

1. 视频概述
2. 主要约束
3. 分段时间轴
4. 每段的镜头级时间轴
5. 镜头 Prompt
6. 备选方案
7. 已自动补全项

## 分段规则

- 先按叙事节拍分段
- 再在每段内部切镜头
- 每段只承担一个阶段任务

## 每段必写项

- 阶段名称
- 起止时间
- 主体状态
- 镜头状态
- 承接关系

## 检查点

- 段与段之间是否有因果或情绪承接
- 是否明确哪些锚点跨段保持一致
- 是否避免每段都重新介绍主体

## 常见失败

- 只有镜头列表，没有段落层
- 每段像独立小片，没有主线
- 跨段角色、服装、场景断裂
