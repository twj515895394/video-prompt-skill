# Single Unit Output Spec

## 目标

规范单片段视频的对外输出，让结果既轻量又够执行。

## 适用场景

- 约 `5s` 左右短片段
- 单一动作推进
- 单一情绪变化
- 单一镜头主任务

## 输出骨架

1. 视频概述
2. 主要约束
3. 镜头级时间轴
4. 镜头 Prompt
5. 备选 Prompt
6. 已自动补全项

## 时间轴粒度

- 通常 `2-4` 个镜头足够
- 不要细到逐帧导演脚本
- 每段都要写主体状态和镜头状态

## 检查点

- 开始状态是否清楚
- 中段推进是否只有一个主重点
- 收尾状态是否能自然停住

## 常见失败

- 单片段写成多段故事
- 镜头数量过多，节奏过碎
- 只写风格不写结束落点
