# Prompt Assembly Control

## 目标

把任务目标、素材职责、时间轴、主体运动、镜头、连续性、表演、音画、风格和限制组织成一份清楚、无重复、可直接执行的通用导演方案。

本页负责信息优先级、组装顺序、压缩、冲突裁决和输出完整性；模型专属语法由 `models/` 转换。

## 何时读取

- 已经有大量设定，但最终 Prompt 冗长、重复或互相冲突；
- 用户给了剧情、镜头、风格、参考素材和限制，需要合成最终交付；
- 多镜头或多片段输出结构不统一；
- 正向描述和负向限制比例失衡；
- 需要从通用方案转换到 Generic、Seedance 或 LTX。

## 信息优先级

发生冲突时使用：

```text
用户当前明确要求
→ 必须保留/必须修改/必须禁止
→ 当前任务 Playbook
→ 输入素材职责绑定
→ 时间轴与核心控制决策
→ 风格和详细资料
→ 自动补全
```

低优先级内容不得覆盖高优先级约束。

## 通用导演方案结构

推荐内部先形成以下中间结构：

```text
1. 任务与输出目标
2. 素材职责和保留边界
3. 全局稳定项
4. 场景、主体和初始状态
5. 绝对时间轴/镜头顺序
6. 每段主体运动
7. 每段镜头状态
8. 表演和音画事件
9. 风格、光影和质感
10. 连续性与失败限制
11. 模型适配信息
```

并非每项都要作为独立标题展示，但最终 Prompt 必须覆盖当前任务真正需要的部分。

## 组装顺序

### 1. 先写任务核心

第一段就明确：

- 生成什么类型的视频；
- 时长或段落规模；
- 唯一主叙事目标；
- 文生、图生、视频参考、编辑、延长或音频驱动等任务性质。

### 2. 再写参考关系

有素材时优先说明：

- 每份素材的职责；
- 人物、服装、场景、动作、运镜和声音分别由谁提供；
- 强保留和禁止继承项。

不要在后文反复重新解释素材职责。

### 3. 建立全局画面和稳定项

只保留跨全片真正稳定的内容：

- 人物身份；
- 场景骨架；
- 主服装和关键道具；
- 画面现实度或渲染方式；
- 主光源和色调；
- 必须贯穿的连续性要求。

动态变化放到时间轴，不要把终态也写成全局固定项。

### 4. 写时间轴或镜头单元

每段使用统一顺序：

```text
时间/镜号 → 主体状态与动作 → 镜头状态 → 表演/声音 → 结束状态
```

同一信息只出现一次。若全局已锁定服装，不必每镜重复完整服装描述。

### 5. 补风格和质感

风格必须转成可执行变量：

- 拍摄来源；
- 观看位置；
- 景别与机位倾向；
- 光源、阴影和色调；
- 材质、环境和画面节奏。

风格不得覆盖主体动作和镜头任务。

### 6. 最后补限制

限制只针对当前高风险失败：

- 身份漂移；
- 动作跳跃；
- 镜头漂浮；
- 道具复制；
- 口型错误；
- 无关元素、文字或水印；
- 当前模型已知高风险项。

通常选择 3-8 个高价值限制，而不是堆满通用负面词。

## 单片段组装骨架

```text

- 0.0-Xs：
- X-Ys：
- Y-结束：
镜头与表演原则：
音画设计：
连续性与失败限制：
```

## 多镜头/多片段组装骨架

```text
全片目标与统一锚点：
素材职责：
段落规划：

Segment 1：
- 段落目标
- 镜头级时间轴
- 结尾交接状态

Segment 2：
- 从上一段什么状态开始
- 镜头级时间轴
- 结尾交接状态

全片声音、风格与连续性：
模型适配：
```

## 去重规则

- 全局稳定项只在开头写一次；
- 时间轴内只写本段变化；
- 不同时使用多个近义风格标签；
- 不在正向描述和负向限制里重复同一句；
- 不重复列出模型已默认继承的参考关系；
- 同一运镜只保留一个明确术语和路线；
- 同一情绪只保留可见表演过程，不再堆抽象同义词。

## 冲突检查

重点识别：

- 固定机位与大幅环绕同时存在；
- 深景深与背景完全虚化同时存在；
- 角色保持静止与完成复杂动作同时存在；
- 完全复刻首帧与彻底改变构图同时存在；
- 慢节奏长镜头与每秒多次切镜同时存在；
- 强保留服装与中途无原因换装；
- 无对白与精准口型要求同时存在；
- 写实纪实与无物理限制的漂浮运动同时存在。

冲突时不并列输出两个互斥要求，应根据优先级裁决并删除低优先项。

## 压缩原则

压缩不是删除关键条件，而是：

- 合并重复描述；
- 把固定内容提升为全局约束；
- 把长术语列表改为一个明确选择；
- 删除不影响结果的装饰词；
- 用结构化时间轴代替散乱故事段落；
- 用素材职责表代替反复解释参考图。

## 模型适配转换

### Generic

保留清楚的自然语言导演结构，不引入假设语法。

### Seedance 2.0

将已完成的素材职责转换成明确的 `@素材` 绑定；只使用确认支持的编辑、延长、音频或参考能力。

### LTX-2.3

将结构化方案转换为连贯自然语言导演段落，保持主体、镜头、表演和声音的时间顺序；图生视频减少静态画面复述，强调接下来发生的运动。

模型适配不能重新改变通用核心已经锁定的剧情和空间逻辑。

## 输出前完整性检查

### 必查

- 任务性质和主目标；
- 输入素材职责；
- 初始状态；
- 主体运动；
- 镜头状态；
- 时间顺序；
- 收尾状态；
- 连续性限制。

### 按需

- 表演和对白；
- 音效和 BGM；
- 多镜承接；
- 风格和光影；
- 模型适配语法。

## 常见失败与修复

### Prompt 很长但不可执行

修复：删除抽象修饰，恢复“主体动作 + 镜头 + 时间 + 落点”。

### 每段重复完整人物设定

修复：把身份、服装和场景提升为全局稳定项。

### 负向词多于正向目标

修复：先补正向动作和镜头逻辑，只保留最相关风险限制。

### 风格词互相竞争

修复：保留一个题材/作者气质和一个设备/观看位置，其余删除。

### 模型语法污染通用层

修复：通用方案先独立完成，最后一步才进入模型适配。

## 输出前检查

- 信息优先级是否正确；
- 是否有互斥要求；
- 全局项与时间轴变化项是否分开；
- 每段是否统一使用相同字段顺序；
- 是否存在大段重复；
- 正向描述是否足以独立成立；
- 负向限制是否针对当前风险；
- 模型适配是否只改变表达方式和能力边界；
- 最终文本是否可以直接复制使用。

## 边界

- 输入职责读取 `reference-binding/control.md`；
- 时间轴读取 `timeline-rhythm/control.md`；
- 具体运镜、动作、表演和音画分别读取对应控制页；
- 输出版式读取 `assets/templates/`；
- 模型语法读取 `references/models/`。
