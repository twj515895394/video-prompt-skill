# Interactive Mode

## 目标

在用户需要共创时，按 `grill-me` 式持续追问，把叙事方向、镜头策略和节拍真正锁定，再输出视频 Prompt。

## 硬规则

1. 每次只问一个问题。
2. 不设固定轮数上限。
3. 能从现有内容推断的，不追问用户。
4. 只追当前最影响结果的变量。
5. 允许指出冲突，比如“想要极稳长镜头，但又想每秒切爆点”。

## 起手方式

### 方向还很散

先给 `2-3` 个方向假设，再让用户挑或改：

- 更偏情绪电影短片
- 更偏动作推进
- 更偏关系段落

### 方向已明确

直接追当前最大缺口，例如：

- “这条视频你最重的是动作推进，还是人物情绪变化？”
- “你给的这张图，更想当首帧、关键帧还是角色锚点？”
- “这段里你最希望观众先看到主体动作，还是镜头压迫？”

## 追问优先级

### 图生视频

- 图像类型
- 必保锚点
- 主体运动
- 镜头运动
- 节拍强弱

### 文生视频

- 开场画面
- 主体运动
- 镜头主任务
- 节奏密度
- 收尾状态

### 多片段

- 段落目标
- 段间承接
- 跨段稳定项
- 每段的镜头主任务

## 收口条件

- 用户明确要求出结果
- 再问只会微调，不再改变主方向
- 开场、推进、收尾、连续性四层已经足够稳

## 最终输出

```text
方向决策摘要：
主方案：
备选方案 A：
备选方案 B：
锁定变量：
剩余自动补全变量：
```

## 反模式

- 不要机械限制自己只问三轮
- 不要一开始就给完整时间轴把用户堵死
- 不要把“共创”做成轻量问答秀
