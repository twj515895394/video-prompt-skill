# Visual Style Appendix

## 使用目标

把“电影感、广告感、短剧感、作者感”拆成可执行的视频风格变量。

## 两层选择

### 设备 / 观看位置层

- 手持
- 固定机位
- 长镜头
- 长焦压缩
- GoPro / FPV
- 玻璃反射

### 作者 / 题材气质层

- 都市孤独
- 家庭克制
- 权力史诗
- 废墟哲思
- 奇幻史诗
- 秩序怪诞

## 组合规则

- 通常 `1` 个设备层 + `1` 个作者气质就够
- 不要同时堆多个互斥世界观
- 风格层必须服务主体运动和镜头任务

## 写法骨架

```text
设备层：
观看位置：
作者 / 题材气质：
光影色调：
限制：
```
