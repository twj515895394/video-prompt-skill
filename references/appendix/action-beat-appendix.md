# Action Beat Appendix

## 使用目标

把“打得很爽、跑得很快、很有冲击力”拆成可拍的动作节拍。

## 基础结构

```text
蓄力 + 接触 + 反馈 + 恢复
```

## 每段动作必写

- 动作目标
- 攻击者或主体姿态
- 接触点
- 受力方向
- 停顿感
- 环境反馈
- 镜头位置

## 适用场景

- 打斗
- 追逐
- 奔跑
- 爆点进入
- 高能反应镜头

## 规则

- 先保动作读得清，再加镜头刺激
- 冲击段不要把主体动作和运镜都拉满
- 爆点必须有落点和恢复，不要一直顶格

## 写法骨架

```text
动作阶段：
主体动作：
接触 / 爆点：
环境反馈：
镜头反应：
收尾状态：
```
