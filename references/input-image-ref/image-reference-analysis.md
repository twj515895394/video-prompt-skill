# Image Reference Analysis

## 目标

把参考图转成视频起点，而不是把静态图误当成完整视频方案。

## 先判图片类型

- 分镜图
- 首帧图
- 尾帧图
- 关键帧图
- 角色图
- 场景图

不同图像类型对应不同视频职责，不要一律按“参考图”处理。

## 默认保留项

用户没有明确说保留什么时，优先保：

- 主体一致性
- 场景锚点
- 光影基调

默认重新生成：

- 运动过程
- 镜头运动
- 节奏展开

## 主图与辅图规则

### 主图负责

- 主体身份
- 主场景锚点
- 主要构图关系

### 辅助图负责

- 妆容
- 服装
- 光影
- 镜头
- 动作局部借用

不做平均融合。

## 输出草稿骨架

```text
图像类型：
```
